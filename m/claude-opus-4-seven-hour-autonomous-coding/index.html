Claude Opus 4 codes unattended for 7 hours; 72.5% on SWE-bench Verified

Anthropic

7 hours (Rakuten)Longest reported autonomous coding run

Claude Opus 4 scored 72.5% on SWE-bench Verified (79.4% with parallel test-time compute) and Rakuten reported it running an open-source refactor independently for 7 hours; it shipped under ASL-3 safeguards with a METR horizon of about 1.7 hours.

How far it has travelled

From a demonstration to real life, in five steps. Empty steps are the point: a demonstration is not a deployment.

What this could change for you

Multi-hour unattended coding is now routine, so one person can ship what used to take a team, and one bad run can delete a company's data.
