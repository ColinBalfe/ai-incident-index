Claude Code wipes a production database and its backups

A developer was migrating a site to shared AWS infrastructure and had Claude Code run Terraform. The state file was missing at first; after the developer supplied it, the agent ran a destroy against production. That removed the VPC, the RDS database with about 2.5 years of course data, and its automated snapshots. AWS support restored the data from an internal snapshot about a day later.

Damage

production outage ~24h; ~1.94M rows (2.5 years, 100k+ users) deleted then restored
