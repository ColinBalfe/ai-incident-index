A user asked the autonomous X-posting crypto agent Lobstar Wilde for a few SOL, citing a relative with tetanus. The agent sent its entire holding of about 52 million LOBSTAR tokens, roughly 5% of supply, instead of a small amount. Observers suspect it misread a raw token amount and was off by a factor of 1,000.

Damage

~52.4M tokens worth ~$250,000 at transfer time; recipient sold for ~$40,000

Sources

The Block, second source. Evidence confidence: medium. The mechanism (unit/decimal misreading) is speculative. Some called the 'accident' a stunt, and token values are volatile. The underlying agent framework was not confirmed.
