CVE-2026-109618 · CVE-2026-109619 · CVSS up to 9.2 · fixed Oct 21, 2026
Updated Oct 27, 2026, 10:45 AM ET

Status: CISA Known Exploited Vulnerabilities: Listed. Exploit attempts: 57,097 (exploit attempts on TU Delft's sensors alone (Cloudflare: millions)). Fixed in PHP 8.2.35, 8.3.36, 8.4.27, 8.5.12.

The full latest note

Day seven, Tuesday morning: America's cyber agency has formally listed the flaws as exploited. CISA added CVE-2026-109618 and CVE-2026-109619 to its Known Exploited Vulnerabilities catalog on Oct 26 (version 2026.10.26, released 22:24 UTC; this run opened the feed directly), with a federal deadline of Oct 29; the third flaw, CVE-2026-115560, is not listed and still has no fix. CISA named no victim and described no attack, and no organization has confirmed a breach by name (ZDNet Korea, Oct 27); Wiz says it has seen no end-to-end success in its own data and that scanner IPs which succeeded against Adel Karimi's decoy servers 'likely contributed' to the listing. So the running story stays PROVEN, not HIT. New numbers: TU Delft's sensors count 57,097 exploitation requests from 626 IPs in 71 countries since Oct 21 (attempts, not successes); Japan has paused 1,090 sites and services, about 40% not yet back (Assured, via ANN/ABEMA); Wiz sees vulnerable exposed machines down about 67%; Censys still counts 32.51M PHP services on an affected version (via The Hacker News). The index's forecast that CISA would list the flaws by Oct 31 resolved yes; it was called a toss-up (50%), so it does not count toward the record either way.

Am I affected? What to do

Fixed PHP releases: 8.2.35 8.3.36 8.4.27 8.5.12. Per Wiz, nearly every PHP version back to 5.4 has at least one affected bug; THN reports every 7.x and 8.x release affected.

If you run a website on PHP (WordPress, Drupal, Magento and most shared hosting), ask your host or developer which version it runs. Older than the releases above: upgrade, or take it offline until you can. Versions before 8.2 will not get an official fix. A third bug, CVE-2026-115560, is not covered by these releases; follow your host's or PHP's guidance on it.

Questions people are asking

What is PHP2Shell?

PHP2Shell is the name for 2 critical flaws in PHP's core engine (CVE-2026-109618, CVE-2026-109619, CVSS up to 9.2), found with the help of AI by Wiz Research with Calif and OpenAI. They let an attacker run code on, or read memory from, a server running PHP without logging in. Fixes shipped on Oct 21, 2026.

Which PHP versions fix PHP2Shell?

The fixed releases are PHP 8.2.35, 8.3.36, 8.4.27, 8.5.12. Per Wiz, nearly every PHP version back to 5.4 has at least one affected bug; THN reports every 7.x and 8.x release affected. Versions before 8.2 get no official fix.

Am I affected?

If a website you run uses PHP (WordPress, Drupal, Magento and most shared hosting do), it was exposed until upgraded to a fixed release. Ask your host or developer which PHP version the site runs; if it is older than the fixed releases above, upgrade or take it offline until you can.

Is PHP2Shell being exploited?

Exploitation requests against TU Delft's honeypots and telescope, Oct 21 08:37 UTC to Oct 26 21:39 UTC, from 626 IPs in 71 countries; 171 IPs sent code or a dropper. Their sensors only; furthest step attempted, not success. Cloudflare's 'millions' (by Oct 22) still stands. Code execution has been confirmed on researchers' decoy servers (honeypots).

Has any organization been hacked through PHP2Shell?

Still no organization confirmed breached by name, even after the KEV listing (ZDNet Korea, Oct 27; BleepingComputer, Oct 27). Wiz (Oct 27) has seen no end-to-end success in its own telemetry; the only confirmed compromises remain Karimi's honeypots. A SOCRadar report on a Japanese real-estate extortion operator found PHP2Shell tooling on the operator's server but 'no link between PHP2Shell and these intrusions'.

Is PHP2Shell on CISA’s Known Exploited Vulnerabilities list?

CISA added CVE-2026-109618 and CVE-2026-109619 to the KEV catalog on Oct 26 (version 2026.10.26, released 22:24 UTC); federal civilian agencies must act by Oct 29; forensic triage required; ransomware use 'Unknown'. CVE-2026-115560 not listed. CISA has named no victim and described no attack. No emergency directive found.

What is CVE-2026-115560?

A third PHP bug disclosed on Oct 23 that the Oct 21 fixes do not cover. PHP issued an informational advisory and is leaving the fix to the next regular release; Korea's KISA published a temporary workaround. No exploitation has been reported.

Did AI find PHP2Shell?

Yes. Wiz Research, Calif and OpenAI used frontier AI models (Wiz Atlas, Gemini 4 Argon, GPT-5.6 Sol) to find and weaponize the flaws in August 2026; they were reported to PHP on Aug 24 and disclosed Oct 21. It is the first AI-found bug to push governments to switch off public services as a precaution.
